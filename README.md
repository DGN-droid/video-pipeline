# video-pipeline

Automated video processing pipeline designed for subtitle generation, segment building, and subtitle burning. Powered by Python, Modal serverless execution, and deployed on Vercel.

---

### Features

- **Subtitle Generation & Building**: Automatically builds `.srt` files from audio/video segments.
- **Subtitle Burning**: Renders and burns subtitles directly onto video files.
- **Serverless Processing**: Utilizes Modal service to handle heavy GPU/CPU processing asynchronously.
- **API Endpoints**: Integrated API for seamless video uploading and upserting handlers.
